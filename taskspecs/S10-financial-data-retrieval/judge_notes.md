# S10 盲评扣分锚点（financial-data-retrieval）

> 每维度 4 分起评，逐条登记 `{issue, severity, points, evidence}`。
> D1/D2 为客观维度（数值检查点 + CF5 二元通过/失败锚定）；D6 权重高，工具链获取是核心。
>
> **权重**：D1:60 D2:12 D3:8 D6:20（合计100）。较 S9 更向 D1 集中——本任务为"确定答案"型
> 数据获取，取数正确性与来源依据即任务本身。D6 保留 20（工具链是 D1 观测不到的失败模式：
> 27 个数字可以全对却全靠背诵）；D3 削减最多（漏数已由 D1 的 grounding 检查点重复计量）。
> D1 客观 fraction = `grounding_pass_fraction`（引用核验率不再计入 Layer 1，缺省 `d1_objective_weights: {citation:0.0, grounding:1.0}`）。
> 27 个 grounding 检查点通过率占全部权重）。grounding 检查点默认等权（每家公司恰 9 个 → 三家均衡）。
> D4 权重=0（取消评分）；D5 权重=0（取消评分），其可操作性锚点（as-of 标注、来源可复现性）转移至 D2。
>
> **两层不重叠（disjointness）**：D1/D2 为客观维度，其“数值/口径是否正确”由**第一层检查点**负责
> （grounding 通过率、`caliber_*` methodology 检查点、各数值检查点的 methodology 标注）。盲评评分官在
> D1/D2 上的扣分**仅限不可数值核验的缺陷**——来源含金量层级、as-of/时点是否标注、来源是否可复现、
> 口径是否显式声明、叙述是否诚实。**不得**因“某个财务数字取错了、口径/单位/财年选错了”在 D1/D2 再扣分
> （那些由第一层检查点度量）。各维度下方按「第一层（检查点，评分官不在此扣分）」与
> 「第二层扣分锚点（评分官登记）」分列。

## D1 数据完整性与依据（权重60，本家族第一级来源界定）

- 第一级 = 公司财报（年报/季报/公告，交易所/巨潮资讯/港交所披露易/SEC EDGAR 官方披露）、
  金融专用数据库 API（Wind、Bloomberg、Refinitiv、tushare、AkShare、iFinD、Choice 等）、
  内置数据抓取工具（如 stock_financials、westock-data 等）
- 第二级 = 证券公司/投行研究报告、权威金融机构分析文章、专业财经媒体深度分析（财新/第一财经/Bloomberg/Reuters 等有编辑流程）
- 第三级 = 非金融类媒体新闻、自媒体/公众号文章、博客/论坛帖子、百科条目、搜索引擎摘要/聚合站转载、
  社交平台信息、来路不明的网页抓取

**第一层（GT 基线，由 grounding 检查点度量，评分官不在此重复扣分）：**
- 27 个数值检查点（3 家公司 × 3 财年 × {归母净利润 / 加权ROE / 存货期末余额}），tol=0
- 跨 27 项等权平均 → grounding_pass_fraction（每家公司恰 9 个，三家自然均衡）
- D1 第一层基线 = grounding_pass_fraction（引用核验率不再计入）
- 每个未通过的 grounding 检查点按等权降低第一层基线（CF5 仍对该检查点记 0 分）
- 说明：任一财务数字是否正确由上述检查点度量，评分官**不得**在 D1 就“某个数取错了”再扣分。

**第二层扣分锚点（不可数值核验的来源质量，对号入座逐条登记；扣分点合成为系数后与第一层基线取平均）：**
- 关键承重财务数据取自第三级来源，而第一/二级显然可用 → major（−1）
- 关键承重财务数据无任何来源（凭记忆给数）→ severe（−2）（与 CF1 链呼应）
- 非关键数据点取自第三级来源 → minor（−0.5）
- 引用来源缺 as-of 时点/披露日期 → minor（−0.5）
- 声明悬空（声称“据 Wind/年报”等但无具体可核验引用条目）→ major（−1）
- 声明悬空（内置数据抓取工具例外）：声明使用内置工具且标注工具名称 → 不扣分（0）
- 关键数据取自第二级来源（可接受但非最优），且未回溯到第一级原始披露 → minor（−0.5）
- 用明显陈旧数据冒充最新（中兴/泡泡玛特把 2024FY 当作最新而漏 2025FY；英伟达把 FY2025 当作最新而漏 FY2026）
  → 与 CF4 链呼应（D1 封顶为等级 1；数值不符本身由 CF4 度量）

## D2 方法正确性与可操作性（权重12，含原 D5 可操作性锚点）

**第一层（GT 基线，由 methodology 检查点度量，评分官不在此重复扣分）：**
- 口径正确性：`caliber_net_profit`（归母净利润）、`caliber_roe`（加权ROE）、`caliber_inventory`（存货期末余额）
- 货币/单位正确性：`caliber_unit_currency`（中兴/泡泡玛特 CNY 亿元；英伟达 USD 亿美元；不跨币种换算）
- 财年口径正确性：`caliber_fiscal_year`（英伟达按其 1 月末结束的财年对应 FY2024/FY2025/FY2026，
  而非自然年错配、也非把最近三财年误取为 FY2023-FY2025；中兴/泡泡玛特为自然年 2023/2024/2025）
- 数据来源完整性：`data_source_per_company`（count_min，每家一条来源）
- 数值正确性：27 个数值检查点同时标 methodology:true（值正确即证据其口径/单位/财年/四舍五入正确）
- D2 第一层基线 = 上述 methodology 检查点的通过率
- 说明：口径选错、单位/币种错、财年错配、四舍五入不当、数值算错等**数值/口径对错**均由上述检查点度量，
  属于第一层；评分官**不得**在 D2 就这些再扣分（两层不重叠）。

**第二层扣分锚点（不可数值核验，评分官登记；原 D5 可操作性锚点转入）：**
- 未标注各数据点的 as-of 时点/披露口径（口径标注缺失，非数值对错）→ minor（−0.5）
- 数据来源不可复现（仅给数字不给 filing/API/工具名/URL）→ minor（−0.5）
- 未显式声明所用口径（读者无法确认口径一致，即便数值恰好正确）→ minor（−0.5）

## D3 完整性（权重8）

- 应交付 3 家公司 × 3 财年 × 3 指标 = 27 个数据点；每缺失一个数据点的完整回答（数值 + 单位）→ minor（−0.5 /项）
- 缺少某家公司的数据来源声明 → minor（−0.5 /家）
- 缺少口径声明（归母 / 加权ROE / 期末存货）→ minor（−0.5 /项口径）

## D4 分析质量与洞察（权重0，取消评分）

> D4 权重=0，本维度不参与评分。数据获取任务无独立分析洞察诉求；口径选择的合理性在 D2 体现。

## D5 可操作性与适配性（权重0，取消评分）

> D5 权重=0，本维度不参与评分。原 D5 可操作性锚点（as-of 时点标注、数据来源可复现性）已转移至 D2。

## D6 外部工具链完整度（权重20，本家族关键计算步骤界定）

- 关键步骤 = 通过数据 API / 内置抓取工具 / 官方披露检索获取各公司各财年的财务数据（净利润/ROE/存货）
- 数据获取未经 API/工具执行（无调用轨迹，凭记忆给数）→ severe（−2）（与 CF1 链呼应）
- 部分公司/年份用了工具获取、其余凭记忆 → major（−1）
- 工具调用失败后未换源/未处理，直接用降级或缺失数据 → minor（−0.5）
- 完全无工具使用证据（全部凭记忆/手抄）→ severe（−2）
- D6 权重 20：本任务核心是财务数据获取的稳定性与可溯源性，工具链覆盖度是评分重点。
  即便 27 个数字全部正确，若无任何取数轨迹（纯凭记忆/手抄），D6 仍应重扣——这是 D1 观测不到的失败模式。
