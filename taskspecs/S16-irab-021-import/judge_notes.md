# S16 盲评扣分锚点（招商银行杜邦分析）

> **每维度 4 分起评，逐条登记 `{issue, severity, points, evidence}`；轻微 −0.5 / 明显 −1 / 严重 −2。**
> 本文件只给「情形 → 既有严重度」映射：不含任何期望数值，不改权重，不新增严重度档，不设加分项。
>
> 权重：D1:20 D2:30 D3:20 D4:20 D5:5 D6:5
>
> **两层不重叠（disjointness）**：D1 与 D2 是客观维度，其「数值/公式是否正确」由**第一层
> 检查点**负责度量。评分官在这两个维度上的扣分**仅限不可数值核验的缺陷**——来源含金量、
> 口径是否声明、概念是否误解、判定是否有可操作方法论支撑。**不得**因检查点已经度量的数值
> 对错在此再扣一次分。

## D1 数据完整性与依据（权重 20）

**第一层（GT 基线，评分官不在此重复扣分）：**

- 逐项外部真值检查点（营业收入/归母净利润/总资产/归母权益 2023-2025年末，共10项）
- 年报披露 ROAE/ROAA（2025/2024，共4项）
- 杜邦三因子与乘积（净利率/周转率/权益乘数/乘积，2025/2024，按 caliber_declared 路由，共8项）
- D1 第一层基线 = 上述 grounding 检查点的通过率
- 说明：具体数字取得对不对，已由第一层度量，评分官不得在此重复扣分。

**第二层扣分锚点（不可数值核验的来源质量，评分官登记）：**

| 情形 | 扣分 |
|---|---|
| 关键财务数据无来源，凭记忆编出来的 | 严重 −2 |
| 关键数据用了非官方渠道（如财经自媒体转引），而招商银行 A 股定期报告本身可查 | 明显 −1 |
| 引用了数据但没标注是 2025 年报还是 2024 年报、或未注明披露日期 | 轻微 −0.5 |
| 全文未声明净利率分子用的是归母净利润还是合并净利润（含少数股东） | 明显 −1 |
| 全文未声明权益乘数分母是否剔除其他权益工具（优先股/永续债） | 轻微 −0.5 |

---

## D2 方法正确性（权重 30，本容器主维度）

**第一层（GT 基线，评分官不在此重复扣分）：**

- `roe_closure_2025`/`roe_closure_2024`（consistency）：候选作品自己报的三因子乘积，是否等于
  自己报的净利率×周转率×权益乘数——这是本题最核心的闭环检查
- `turnover_2025`/`turnover_2024`/`leverage_2025`/`leverage_2024`/`roe_product_2025`/
  `roe_product_2024`（gt_variants 按声明口径路由）：三因子与乘积本身取值是否正确
- D2 第一层基线 = 上述 methodology 检查点的通过率
- 说明：**乘积闭环红线（三因子相乘是否等于自报乘积）已由 `roe_closure_*` 检查点机械核验**，
  评分官不得在此就"乘积算错了"再扣一次分；跨年口径漂移、分子分母错配等若导致乘积与
  三因子对不上，同样已被第一层捕获。

**第二层扣分锚点（不可数值核验的口径/概念缺陷，评分官登记）：**

| 情形 | 扣分 |
|---|---|
| 把三因子乘积（自算的归母全口径 ROE）等同于年报披露的加权平均 ROAE，未说明二者口径不同（ROAE 分母剔除其他权益工具并按时间加权，分子扣除对应股息/利息） | 明显 −1 |
| 方向/叙述与自报数值矛盾：如权益乘数数值上升，文字却说"杠杆收缩拖累 ROE"；或周转率数值下降，结论却写"资产周转效率稳中有升" | 严重 −2 |
| 单位/数量级表述前后不一致：如周转率一处写 0.0258（次），另一处写成 2.58 次（10×/100× 漂移）；注意 2.58% 与 0.0258 是同一值的两种合法写法，本条只针对真正的数量级错误 | 明显 −1 |
| 净利率一年用归母净利润、另一年用合并净利润（含少数股东）而未注明，造成跨期口径不一致 | 明显 −1 |
| 明确并行展示期末口径与平均口径两套杜邦且各自闭环 | **不扣分** |
| 用营业净收入（而非营业收入）作净利率分母，且两年同口径自洽、已声明 | **不扣分** |
| 明确指出三因子乘积与披露 ROAE 因口径不同而不相等，这正是正确做法 | **不扣分** |

## D3 完整性（权重 20）

| 情形 | 扣分 |
|---|---|
| 2025 年三因子（净利率/周转率/权益乘数）缺任一项，或未标明口径 | 明显 −1 |
| 只算 2025 年单年，未给 2024 年同口径三因子值作对比基准 | 严重 −2 |
| 未给出两年的三因子乘积（题面显式要求） | 明显 −1 |
| 未说明与 2024 年相比各因子的变动方向与幅度 | 明显 −1 |
| 主驱动结论骑墙（如"净利率和周转率都有影响"而不给出明确的主驱动因子） | 明显 −1 |

## D4 分析质量与洞察（权重 20）

| 情形 | 扣分 |
|---|---|
| 量化归因缺失：只做方向性描述（如"某因子涨/跌了所以是主因"），未用连环替代法/对数分解给出各因子对 ROE 变动的 pp 级贡献 | 明显 −1 |
| 识别出主驱动因子后，未拆解其背后的经营机制（如从收入端增速、资产/负债规模扩张节奏、净息差、拨备计提等银行经营维度解释该因子为何变动，而只停留在"该因子涨了/跌了"这一事实陈述） | 明显 −1 |
| 三因子中出现方向相反的变化（有升有降）时，未讨论"升"的因子为何未能抵消"降"的因子对 ROE 的拖累，或未评估这种抵消/托底作用是否可持续 | 明显 −1 |
| 口径混乱：把年报披露 ROAE 直接当成三因子乘积的目标值，未意识到二者是两套口径 | 明显 −1（与 D2 第二层对应缺陷不重复计分，此处针对分析叙述本身，D2 针对是否声明口径） |
| 完全未提及降幅的口径敏感性（不同口径下降幅幅度不同）或未把本期 ROE 变化放入连续趋势中解读 | 轻微 −0.5 |

**加分不存在**：本框架为纯扣分制。

## D6 外部工具链完整度（权重 5）

**本家族的关键计算步骤**：从原始财务数据算出净利率/周转率/权益乘数三因子，再验证三因子乘积
与自报乘积的闭环。

| 情形 | 扣分 |
|---|---|
| 完全无任何工具/计算证据（纯记忆/手算给出关键数字） | 严重 −2 |
| 声称的计算未经代码/工具执行，无执行轨迹、无可复现产物 | 明显 −1 |
| 工具链覆盖不完整：部分关键步骤有工具支撑，其余没有 | 轻微~明显 −0.5~−1 |
| 工具调用失败后未处理、未换源，直接使用降级或缺失的结果 | 轻微 −0.5 |

D6 只评工具使用行为，不评数据来源层级（那由 D1 负责）。
