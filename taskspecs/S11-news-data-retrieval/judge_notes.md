# S11 盲评扣分锚点（news-data-retrieval / 金融消息面 Web Search）

> 每维度 4 分起评，逐条登记 `{issue, severity, points, evidence}`。
> D1/D2 为客观维度（检查点 + CF5 二元通过/失败锚定）；D6 权重高，web search 取数是核心。
>
> **权重**：D1:60 D2:12 D3:8 D6:20（合计100），与 S10 完全一致——本任务同为"确定答案"型取数，
> 答对与来源依据即任务本身。D6 保留 20（工具链是 D1 观测不到的失败模式：12 个分点可以全对却
> 全靠训练记忆，消息面任务的记忆尤其不可靠）；D3 削减最多（漏答已由 D1 的分点重复计量）。
> D1 客观 fraction 内部权重 `citation:0.3 / grounding:0.7`（引用抽样核验占 0.3，
> 题库分点通过率占 0.7）。D4 权重=0、D5 权重=0（均取消评分，D5 的可操作性锚点转移至 D2）。
>
> **两层不重叠（disjointness）**：D1/D2 为客观维度，其"答案/口径是否正确"由**第一层检查点**负责。
> 盲评评分官在 D1/D2 上的扣分**仅限不可数值核验的缺陷**，且 **D1 的第二层在本任务被整体取消**
> （见下）。**不得**因"某个日期/价格/金额答错了"在 D1/D2 再扣分——那些由第一层检查点度量。
> 各维度下方按「第一层（检查点，评分官不在此扣分）」与「第二层扣分锚点（评分官登记）」分列。

## D1 数据完整性与依据（权重60）

**第一层（GT 基线，由 grounding 检查点度量，评分官不在此重复扣分）：**
- 题库 12 个分点（题目一 3 + 题目二 3 + 题目三 6），由 13 个 grounding 检查点承载，
  经 `grounding_group_weights` 组装为 12 个等权分点：
  - 唯一的部分分分点（三个 API 价格）：`all3` 腿（全对）0.5 + `set` 腿（至少答对两项）0.5
    → 三项全对 1.0 / 恰对两项 0.5 / 其余 0.0
  - 两个"全对才给分"的分点（交易条款、两日会谈窗口）各由单条 `vector` 检查点实现：
    任一成员错或缺则整分点不给，**不给部分分**
  - 时间线中三个存在多来源口径差异的日期按题库容错规则接受相邻两日（半整数中点 + tol 0.5）；
    其余日期无容错
- 12 个分点等权平均 → grounding_pass_fraction
- D1 第一层基线 = 0.3 × citation_verified_fraction + 0.7 × grounding_pass_fraction
- 每个未通过的分点按等权降低第一层基线（CF5 仍对该检查点记 0 分）
- 说明：任一答案是否正确由上述检查点度量，评分官**不得**在 D1 就"某个答案答错了"再扣分。

**第二层扣分锚点：本任务【取消】——评分官在 D1 不登记任何扣分项（第二层扣分恒为 0）。**

- 取消范围：data-retrieval 家族通行的**信息来源含金量三级锚点**（第三级来源 / 无来源 /
  声明悬空 / 缺 as-of / 未回溯一手来源等）在 S11 **一律不适用，不得登记**。
- 取消理由：本任务是**消息面 web search**任务。可得来源天然以新闻机构时间线、官方定价页、
  交易所公告、监管披露与百科类词条混合为主，同一事实往往只有媒体口径可依（题库本身就在
  「口径说明」中承认 AP / Britannica / 议会图书馆 / ABC News 等来源存在 ±1 天差异，并据此
  设置容错）。在这种来源结构上套用面向公司财报的三级含金量分级，会把"引用了新闻机构时间线"
  这一**题目本身要求的正确做法**判为降级，属于系统性误判。
- 来源质量并未失去约束，只是改由其他通道承担，避免重复计量：
  - 引用是否存在、是否支撑主张、是否新鲜 → 第一层的 `citation_verified_fraction`（占 D1 的 0.3）
  - 是否真的检索而非凭记忆 → **D6**（工具链，权重 20）
  - 是否声明来源、是否标注 as-of 与口径 → **D2** 第二层
  - 捏造来源/公告 → CF1（人工确认闸门）；拿陈旧消息冒充最新 → CF4（D1 封顶等级 1）
- 因此 D1 的分数 = 第一层实测基线（不再减第二层）。评分官若发现来源层面的问题，
  应登记到 D2 或 D6 的对应锚点，**不要**登记到 D1。

## D2 方法正确性与可操作性（权重12，含原 D5 可操作性锚点）

**第一层（GT 基线，由 methodology 检查点度量，评分官不在此重复扣分）：**
- 日期口径：`caliber_dates_with_year`（所有日期写明年份）、
  `caliber_event_date_basis`（以事件实际发生日/政策生效日为准，多来源差异时说明所采口径）
- 精确值口径：`caliber_precise_official_values`（用题目指定来源/监管原文/官方定价页的精确值，
  而非未经说明的媒体约数）
- 时点口径：`caliber_asof_cutoff`（声明题设的数据核验时点并据此界定"最新"）
- 来源完整度：`data_source_per_question`（count_min，每道大题一条来源）
- D2 第一层基线 = 上述 methodology 检查点的通过率
- 说明：上述口径项"有没有做到"由检查点度量，属第一层；评分官**不得**在 D2 就这些再扣分。

**第二层扣分锚点（不可数值核验，评分官登记；原 D5 可操作性锚点转入）：**
- 存在多来源口径差异的时间点，作答未说明自己采用的是哪一口径（发生日/宣布日/生效日、时区）
  → minor（−0.5）
- 引用来源不可复现（只给机构名或链接文字，无标题/日期/可定位信息）→ minor（−0.5）
- 引用来源缺 as-of / 发布日期标注 → minor（−0.5）
- 声明悬空：声称"据官方公告/官方定价页"但未给出任何可定位的具体来源条目 → major（−1）
- 用约数或区间替代可获得的精确值，且未说明为何只能给约数 → minor（−0.5）
- 价格未标明币种与计价单位（题目已要求以美元作答，作答却不标币种/不标每多少 token）
  → minor（−0.5）
- 把不同事件混为一谈（例如把"宣布"与"生效"、"宣布复航"与"实际复航"、"会谈"与"签署"当作同一
  事件）而未加区分 → major（−1）

## D3 完整性（权重8）

- 应交付 12 个分点的完整回答；每缺失一个分点的完整回答（答案 + 必要单位/币种/年份）→ minor（−0.5 /项）
- 复合分点只答一半（例如三个价格只报两个、两日会谈只给一天、只给交易金额不给持股比例）
  → minor（−0.5 /项）
- 缺少某道大题的数据来源声明 → minor（−0.5 /道）
- 以"无法确定/需进一步核实"代替回答，且未给出任何候选答案 → 按缺失该分点计（−0.5 /项）
- 对同一问题给出多个互相排斥的候选答案而不指明采用哪一个（骑墙式作答）→ minor（−0.5 /项）

## D4 分析质量与洞察（权重0，取消评分）

> D4 权重=0，本维度不参与评分。消息面取数任务无独立分析洞察诉求；口径选择的合理性在 D2 体现。

## D5 可操作性与适配性（权重0，取消评分）

> D5 权重=0，本维度不参与评分。原 D5 可操作性锚点（as-of 标注、来源可复现性）已转移至 D2。

## D6 外部工具链完整度（权重20，本家族关键步骤界定）

- 关键步骤 = **通过 web search / 抓取工具 / 官方披露检索**获取每道题的事实（模型型号与官方定价、
  公告与业绩承诺条款、时间线各事件日期），而非依赖训练记忆。
- 完全无检索/工具使用证据（全部凭记忆或手抄）→ severe（−2）
- 部分题目经检索获取、其余凭记忆 → major（−1）
- 有检索动作但未落到承重事实上（只搜了背景，关键日期/价格仍凭记忆）→ major（−1）
- 检索失败/结果冲突后未换源、未交叉核验，直接采用单一可疑结果 → minor（−0.5）
- 仅给出搜索关键词或"我查了"之类的自述，无任何可查的检索轨迹或来源条目 → minor（−0.5）
- D6 权重 20：本任务核心是消息面事实的可检索性与可溯源性，工具链覆盖度是评分重点。
  即便 12 个分点全部正确，若无任何检索轨迹（纯凭记忆），D6 仍应重扣——这是 D1 观测不到的
  失败模式，且在消息面任务上尤其危险（训练记忆对新闻的时效性最不可靠）。
