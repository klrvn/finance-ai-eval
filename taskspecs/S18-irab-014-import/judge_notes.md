# S18 盲评扣分锚点（五粮液多空综合分析）

> **每维度 4 分起评，逐条登记 `{issue, severity, points, evidence}`；轻微 −0.5 / 明显 −1 / 严重 −2。**
> 本文件只给「情形 → 既有严重度」映射：不含任何期望数值，不改权重，不新增严重度档，不设加分项。
>
> 权重：D1:30 D2:20 D3:15 D4:30 D5:0 D6:5
>
> **两层不重叠（disjointness）**：D1 与 D2 是客观维度，其「数值/公式是否正确」由**第一层
> 检查点**负责度量。评分官在这两个维度上的扣分**仅限不可数值核验的缺陷**——来源含金量、
> 口径是否声明、概念是否误解、判定是否有可操作方法论支撑。**不得**因检查点已经度量的数值
> 对错在此再扣一次分。
>
> **本题的特殊性**：批价（挂牌 vs 实际成交）、渠道库存、股息率区间、回购/集团增持计划、
> 账上货币资金——这些量 gold 原文本身就是区间/多口径，没有单一正确值。以区间建模、标注
> 口径、明说是假设——是正确行为，不是缺陷；不要因为看到"约""区间""假设"就扣分。
>
> **盲评隔离说明**：本题要求候选作品同时给出看多与看空两方逻辑，gold 本身也未预设一个
> "唯一正确的最终方向"（多空双方各有真实依据）。因此本文件保留了 gold 原文对多空双方
> 论据的具体描述作为"深度参照"——这些是判断分析**深度**够不够的参照标准，不是要求候选
> 作品必须得出某个特定方向的结论；评分官不得因候选作品的最终倾向性结论是多头或空头而
> 加减分，只评估其论证是否扎实、是否覆盖了应有的角度。

---

## D1 数据完整性与依据（权重 30）

**第一层（GT 基线，评分官不在此重复扣分）：**

- 重述前/重述后前三季度数字（4项）
- FY2025全年（重述后，5项）、历史对照FY2024/FY2023（3项）
- 2025分季度营收/净利润（8项）、2026Q1（4项）
- 合同负债（3项）、分红总额与分红率（2项）
- 估值（市值/PB/PE/股价，4项）
- 贵州茅台/泸州老窖/白酒行业可比数据（11项）
- D1 第一层基线 = 上述 grounding 检查点的通过率
- 说明：具体数字取得对不对，已由第一层度量，评分官不得在此重复扣分。

**第二层扣分锚点（不可数值核验的来源质量，评分官登记）：**

| 情形 | 扣分 |
|---|---|
| 关键财务/估值数据无来源，凭记忆编出来的 | 严重 −2 |
| 关键数据用了非官方渠道（自媒体/公众号），而公司公告/年报本身可查 | 明显 −1 |
| 引用了数据但未注明是重述前还是重述后口径 | 明显 −1（与 D2 呼应，此处针对来源标注本身） |
| 引用了数据但未注明数据来源与时点（as-of） | 轻微 −0.5 |
| 张冠李戴：把贵州茅台或泸州老窖的财务/估值/批价数据误记到五粮液名下 | 严重 −2（与 CF1 链呼应） |
| 凭空给出离谱的渠道/批价数字，且无法追溯来源；诚实说明未取到数据不算失真 | 严重 −2 |

## D2 方法正确性（权重 20）

**第一层（GT 基线，评分官不在此重复扣分）：**

- `q_revenue_sum_consistency`/`q_np_sum_consistency`（consistency）：候选作品自己报的
  四个季度数字之和，是否等于自己报的全年数字——这是本题最核心的口径混算红线检查
- `restated_caliber_declared`/`valuation_metric_choice_declared`（present）：是否声明
  财务数字用的是重述前/后口径、是否说明选用的估值指标
- D2 第一层基线 = 上述 methodology 检查点的通过率
- 说明：**Q4 口径混算红线已由 `q_revenue_sum_consistency` 机械核验**（若候选作品用重述前
  前三季减重述后全年得出一个荒谬的 Q4 负值，季度之和就不会等于自报全年数字），评分官不得
  在此就"Q4 算错了"再扣一次分。

**第二层扣分锚点（不可数值核验的口径/概念缺陷，评分官登记）：**

| 情形 | 扣分 |
|---|---|
| 把 FY2025 营收/归母净利润的同比大幅下滑（重述后 vs 重述前旧口径 2024 年）直接解读为经营断崖/业绩塌方，未点明这一降幅主要来自收入确认会计政策变更的追溯重述 | 严重 −2 |
| 将 PE(TTM) 直接用作"估值贵不贵"的唯一依据，未意识到该读数因重述后净利分母被压低而虚高，未替换或补充其他估值指标（如 PB/股息率/前瞻 PE） | 明显 −1 |
| 新旧确认口径直接同比（如用 2025 新口径与 2024 旧口径直接算同比降幅）而未说明口径切换，夸大或缩小了真实变化幅度 | 明显 −1 |
| 批价两口径（挂牌 vs 实际成交）混用，同一处比较或前后引用而未注明是哪个口径 | 明显 −1 |
| 分红"率"与分红"额"混用，或把重述后低基净利算出的分红率当成常态分红率解读 | 明显 −1 |
| 五粮液、贵州茅台、泸州老窖的估值倍数直接并列比较排名，未注明五粮液的 PE(TTM) 因重述而失真、不宜直接同口径横向比较 | 明显 −1 |
| 明确说明所引数字的口径（重述前/后）并全文保持一致 | **不扣分** |
| 明确指出 PE(TTM) 失真并主动替换为 PB/股息率/前瞻 PE 等指标 | **不扣分** |

## D3 完整性（权重 15）

| 情形 | 扣分 |
|---|---|
| 缺少关键经营与财务数据汇总（营收/利润/毛利率/合同负债/动销库存/批价等），或数据未成表 | 明显 −1 |
| 缺看多（bull）逻辑，或看多逻辑只有结论没有支撑证据 | 严重 −2 |
| 缺看空（bear）逻辑，或看空逻辑只有结论没有支撑证据 | 严重 −2 |
| 结论骑墙（如"多空皆有可能，需持续观察"而不给出明确倾向），未落到有倾向性的综合判断 | 明显 −1 |
| 未纳入近期（如最近一个季度以内）发生的重大事项（如业绩变化、监管问询、管理层变动、评级调整） | 明显 −1 |

## D4 分析质量与洞察（权重 30，本容器最看重的判断维度）

| 情形 | 扣分 |
|---|---|
| 缺少口径定性这一前置分析：未厘清 FY2025 营收/净利大幅波动主要是会计口径变更的追溯重述，而非经营塌方，导致后续多空判断的事实基础出错 | 严重 −2 |
| 看多逻辑浅：只罗列数据不解释逻辑（如只说"2026Q1增长快"而不联系合同负债变化、渠道回款、估值安全边际等多个维度形成完整论证） | 明显 −1 |
| 看空逻辑浅：只罗列数据不解释逻辑（如只说"批价倒挂"而不联系经销商现金流、动销质量、竞争格局、治理风险等维度形成完整论证） | 明显 −1 |
| 综合判断未真正"权衡"：只是把看多看空逻辑各自罗列后简单拼接，未在会计口径正本清源的基础上对比双方证据强弱、未点明关键观察变量（后续应跟踪什么指标验证/否证当前判断） | 明显 −1 |
| 结论方向本身缺乏依据支撑（如给出的方向性结论与自己列出的看多/看空证据强弱明显不匹配，例如证据里看空理由远多于且更具体，结论却给出强烈看多而不解释为何看空理由不成立） | 明显 −1（评分官只判断结论与自陈证据是否自洽，不对结论方向本身打分） |

**加分不存在**：本框架为纯扣分制。

## D6 外部工具链完整度（权重 5）

**本家族的关键计算步骤**：财务数据检索（年报/季报/公告，需数据源/工具查询）+ 估值数据
检索（市值/PB/PE等，需市场数据源）+ 季度数字与全年数字的算术复核。

| 情形 | 扣分 |
|---|---|
| 完全无任何工具/检索证据（纯记忆给出全部关键数字） | 严重 −2 |
| 声称检索了数据，但无检索轨迹、无可复现来源 | 明显 −1 |
| 部分数据类别（如财务数据）有检索证据，部分类别（如估值/可比公司数据）没有 | 轻微~明显 −0.5~−1 |
| 工具调用失败后未处理、未换源，直接使用降级或缺失的结果 | 轻微 −0.5 |

D6 只评工具使用行为，不评数据来源层级（那由 D1 负责）。
