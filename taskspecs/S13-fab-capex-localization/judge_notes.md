# S13 盲评扣分锚点（capex-allocation · 存储扩产国产设备受益测算）

> 每维度 4 分起评，逐条登记 `{issue, severity, points, evidence}`；轻微 −0.5 / 明显 −1 / 严重 −2。
> 本文件只给「情形 → 既有严重度」映射：不含任何期望数值，不改权重，不新增严重度档，不设加分项。
>
> 权重：D1:20 D2:30 D3:20 D4:10 D5:5 D6:15。
>
> **两层不重叠（disjointness）**：D1 与 D2 都是客观维度，其「数值与闭合关系对不对」由**第一层
> 检查点**负责。评分官在 D1/D2 上的扣分**仅限不可数值核验的缺陷**——来源含金量层级、口径与
> as-of 是否标注、口径叙述是否诚实、假设是否透明。**不得**因「某个金额算错了」「勾稽没平」
> 「占比合计不对」在 D1/D2 再扣一次分；那些由第一层度量。各维度下方已按「第一层（检查点，
> 评分官不在此扣分）」与「第二层扣分锚点（评分官登记）」分列。
>
> **本题的特殊性，评分官务必先读**：这道题**没有唯一正确答案**。单万片设备投资单价存在两套
> 相差近三倍的合法口径，各工艺环节价值量占比、各环节国产化率、各公司在各环节的内部份额，
> 权威来源全部以区间发布，公司份额更是从未公开披露。因此：
>
> - **以区间建模、标注所采口径与来源、明说「这是假设」——是本题的正确行为，不是缺陷。**
>   看到「约」「区间」「假设」不要扣分。
> - **反过来，给出精确到小数点的点值却不交代口径与来源，才是缺陷**（伪精确）。
> - 不要因为某份作品的数字与你自己的预期不同而扣分。你要评的是它的口径纪律与自洽性，
>   不是它的数字是否等于某个你心中的答案。

## D1 数据完整性与依据（权重 20）

**本家族的数据来源含金量分级：**

- **第一级** = 招股说明书与上市公司定期报告/公告、交易所与巨潮资讯官方披露、金融专用数据库
  API（Wind / Bloomberg / iFinD / Choice 等）、证监会等监管机构的官方批复与披露、
  内置数据抓取工具（如 stock_financials、westock-data 等，作品在数据来源章节声明了工具名称即可）
- **第二级** = 证券公司研究报告（广发/东吴/中泰/华金/万联等）、SEMI 等行业协会统计、
  财新/第一财经/经济观察报/证券时报等有编辑流程的财经媒体深度报道
- **第三级** = 自媒体与公众号文章、百科条目、聚合站转载、搜索引擎摘要、社交平台信息、
  来路不明或无法追溯原始出处的网页抓取内容

> 说明：本题的环节价值量占比与国产化率，权威来源本就以券商研报与行业协会统计为主，
> **取自第二级来源属正常且恰当，不因此扣分**。第二级扣分只适用于「明明有第一级来源可用
> 却没用」的情形——典型是各设备厂商的营业收入（年报/公告可查）与长鑫招股书口径的数据。

**第一层（GT 基线，由 grounding 检查点度量，评分官不在此重复扣分）：**

- 9 家国产设备厂商 2025 年营业收入（相对弹性的分母基数）
- 长鑫科技 IPO 的两个招股书锚点，以及北方华创持有芯源微的股权比例
- 长江存储武汉三期新产线国产设备采购占比（时效性探针）
- D1 第一层基线 = 上述 grounding 检查点的通过率
- 说明：这些数字取得对不对由检查点度量。评分官**不得**因「某个营收数字取错了」在 D1 扣分。

**第二层扣分锚点（不可数值核验的来源质量；扣分点合成为系数后与第一层基线取平均）：**

- 关键承重量化数据取自第三级来源，而第一/二级来源显然可用 → major（−1）
- 关键承重量化数据无任何来源（凭记忆给数）→ severe（−2）（与 CF1 链呼应）
- 非关键数据点取自第三级来源 → minor（−0.5）
- 引用来源缺年份/季度/as-of 时点 → minor（−0.5）
- 声明悬空（声称「据 Wind」「据券商研报」但无具体可核验的引用条目）→ major（−1）
- 声明悬空（内置数据抓取工具例外）：声明使用内置工具且标注了工具名称 → 不扣分（0）
- 各设备厂商营业收入取自第二级转述而未回溯到年报/公告 → minor（−0.5）
- 万业企业 2025 年营收无可信结构化数据：作品若留空或标注「待查」→ **不扣分**；
  若给出一个无来源的具体数字 → major（−1）（与 CF1 链呼应）
- 用明显陈旧的国产化率或扩产/上市状态冒充当期 → 与 CF4 链呼应（D1 封顶为等级 1；
  数值本身不符由第一层与 CF4 度量，评分官在此只登记「未标注口径时点」这一表述缺陷）

## D2 方法正确性（权重 30）

**第一层（GT 基线，由 methodology 检查点度量，评分官不在此重复扣分）：**

- 各厂环节占比合计的自洽性
- 单线设备总额、环节设备额、单厂国产合计三级级联的公式闭合
- 公司层汇总与环节层国产合计的勾稽闭合
- 光刻环节国产受益的量级
- 整线国产受益比例所处的量级
- DRAM 与 NAND 两厂「刻蚀 + 薄膜沉积」合计占比各自所处的区间
- D2 第一层基线 = 上述 methodology 检查点的通过率
- 说明：勾稽平不平、占比合计对不对、光刻是否被给了不该有的受益、两厂占比向量是否雷同，
  **全部由第一层度量**。评分官**不得**在 D2 就这些再扣分。

**第二层扣分锚点（不可数值核验的口径纪律，评分官登记）：**

- 同一条分摊链里混用不同口径的国产化率（中国大陆整体 / 晶圆厂平均 / 目标厂三期 /
  最先进平台）而未逐处标注所采口径 → major（−1）
- 把「单万片总投资」当作「单万片设备投资」直接往下分摊，未说明设备占总投资的比重
  → major（−1）
- 把一次性扩产设备订单同时又当作可循环的年度收入增量 → major（−1）
- 同一笔金额一处标为「订单（含税合同）」另一处标为「收入（不含税确认）」而数值不变
  → minor（−0.5）
- 人民币与美元计价的单价未经汇率换算即相加 → major（−1）
- 把 HBM 或先进逻辑的单万片单价套到普通存储情景，却仍标注为普通 DRAM/NAND → severe（−2）
- 长鑫「拟募资额」与「募投项目总投资」（含自筹）混标为同一口径，或与其他公司的「实募额」
  并列比较而未说明口径差异 → minor（−0.5）
- 北方华创与其并表子公司芯源微在公司层汇总中同时单列而未注明并表关系 → major（−1）
  （重复计数导致的数值不闭合由第一层的勾稽检查点度量；此处只登记「未披露并表关系」这一
  表述缺陷，两者不重叠）
- 某一工艺环节内各公司的国产内部份额之和超过该环节的国产金额 → major（−1）
- DRAM 与 NAND 使用了同一套环节占比向量（第一层的两条互不相交的区间已能捕获多数情形；
  此处只登记第一层未覆盖的表述性情形，如文字声称两厂结构不同但表中实为同一列引用）
  → major（−1）
- 单价、环节占比、国产化率、公司份额中任一类未做成可调假设格，而是硬编码点值
  → major（−1）（若整份作品完全没有公式层，则由 D3/D6 与 CF3 承担，此处不重复登记）
- 明确标注了「假设」「区间」「约」并给出口径来源的对冲表述 → **不扣分（0）**；
  各环节占比或国产化率取区间的不同端点、但各自标注清楚 → **不扣分（0）**

## D3 完整性（权重 20）

- 五层级联骨架（扩产假设 → 分环节拆分 → 国产化率分摊 → 落到公司 → 订单增量）缺任一层
  → severe（−2）
- 未把 DRAM（长鑫）与 3D NAND（长存）分别建模成两块 → major（−1）
- 交付物无可检查的公式层（纯文字结论、纯贴数表格，或仅口头描述框架）→ severe（−2）
  （与 CF3 链呼应）
- 仅引用外部未附文件（「见附件 model.xlsx」而不展开公式与数值）→ 相关计算槽视为缺失，
  按缺失的层数逐条登记 → major（−1 /层）
- 工艺环节覆盖不足（题面点名的刻蚀、薄膜沉积、清洗、量测检测有缺失）→ major（−1）
- 未补齐光刻、CMP、离子注入、涂胶显影、热处理等主要环节 → minor（−0.5）
- 缺少勾稽校验（公司层汇总与环节层国产合计的互相闭合）→ major（−1）
- 缺少数据来源与口径标注区 → major（−1）
- 覆盖的国产厂商过少，主要受益公司有遗漏 → minor（−0.5）
- 表的张数、行列布局、配色、中文标签措辞、是否做图表美化、是否含敏感性页
  → **不扣分（0）**（题面明示框架自由设计）
- 公司覆盖未穷尽到每一家小标的 → **不扣分（0）**（覆盖主要受益厂商即可）

## D4 分析质量与洞察（权重 10）

- 未识别「光刻在设备开支中占比最大、国产化率却近乎为零」这一背离，或未解释其对国产
  受益上限的含义 → major（−1）
- 高端量测同类背离（占比可观而国产化率低）未提及 → minor（−0.5）
- 未讨论设备订单与收入确认之间的时滞，把订单增量直接当作业绩弹性 → major（−1）
- 未说明 DRAM 与 NAND 设备结构差异的成因（高深宽比刻蚀、叠层填充等）→ minor（−0.5）
- 未提示结论对口径假设的高敏感性（单价与国产化率的取值会使受益成倍变化）→ major（−1）
- 结论为套话，未落到具体环节与公司的竞争位置 → major（−1）
- 未识别北方华创因横跨多环节且并表芯源微而应为受益最大一家 → minor（−0.5）

## D5 可操作性与适配性（权重 5）

- 只给绝对订单额，未给「订单增量 ÷ 2025 年营业收入」的相对弹性 → major（−1）
- 给了相对弹性但未指出单一环节/中小市值公司的弹性通常高于平台型大厂 → minor（−0.5）
- 未说明按真实计划产能放大情景时该改哪几格假设 → minor（−0.5）

## D6 外部工具链完整度（权重 15）

**本家族的关键计算步骤界定** = 五层级联的公式求值：产能 × 单价、单线总额 × 环节占比、
环节额 × 国产化率、按份额分摊到公司、公司层汇总与勾稽校验。

- 宣称的测算未经工作簿公式或代码执行（无公式层、无执行轨迹、无可复现产物）→ major（−1）
- 只有部分层有公式支撑，其余层是手填的静态数字 → minor ~ major（−0.5 ~ −1）
- 交付了工作簿但公式层被替换为数值（改假设格不会引起重算）→ major（−1）
- 工具调用失败后未换源、未处理，直接使用降级或缺失的结果 → minor（−0.5）
- 完全无任何工具或公式使用证据（全部凭手算给数）→ severe（−2）

> D6 只评工具使用行为（计算是否真的被执行、工具链覆盖是否完整），**不评数据来源层级**——
> 数据来源含金量由 D1 评估。同一事实缺陷若已触发 CF3，D6 仍可就「无执行工具链」独立扣分。
