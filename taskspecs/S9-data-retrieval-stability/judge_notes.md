# S9 盲评扣分锚点（data-retrieval-stability）

> 每维度 4 分起评，逐条登记 `{issue, severity, points, evidence}`。
> D1/D2 客观锚定（数值检查点 + CF5 二元通过/失败）；D6 权重高，工具链获取是核心。
>
> **v2.3 权重与 D1 客观锚定变更**：D1:40 D2:20 D3:15 D6:25（合计100）。
> D1 客观 fraction = `grounding_pass_fraction`（引用核验率不再计入 Layer 1，缺省 `d1_objective_weights: {citation:0.0, grounding:1.0}`）。
> grounding 检查点由"最终答案"细化为 **Q1-Q4 每题 base_price / latest_price / answer 三元（4:4:2 加权）**。
> 示例：Q1 基准价 PASS、最新价 FAIL、答案 FAIL → Q1 加权通过率 = 0.4*1 + 0.4*0 + 0.2*0 = 0.40 = 40%。
> 跨 4 题等权平均得 grounding 加权通过率即为 D1 客观 fraction（引用核验率不再计入 Layer 1）。
> D4 权重=0（取消评分），D5 权重=0（取消评分），D5 原有可操作性扣分锚点（as-of 时点标注、数据来源可复现性）转移至 D2。
>
> **v2.4 两层不重叠（disjointness）**：D1/D2 为客观维度，其"数值/口径是否正确"由**第一层检查点**负责
> （grounding 通过率、`*_adjustment`/`*_base_date` methodology 检查点）。盲评评分官在 D1/D2 上的扣分
> **仅限不可数值核验的缺陷**——来源含金量层级、as-of/时点是否标注、来源是否可复现、叙述是否诚实。
> **不得**因"某个价格/收益率算错了、复权口径选错了、基准日取错了"在 D1/D2 再扣分（那些由第一层检查点度量）。
> 各维度下方已按「第一层（检查点，评分官不在此扣分）」与「第二层扣分锚点（评分官登记）」分列。
>
> **v2.5 题量变更**：原 Q5（10 年期美债收益率）已从任务中删除。本任务为 **4 题（Q1-Q4）**，
> 全部为 YTD 收益率题。维度权重不变（D1:40 D2:20 D3:15 D6:25）；引用核验已整体关闭（citation_policy: none）。

## D1 数据完整性与依据（权重40，本家族第一级来源界定）

- 第一级 = 金融专用数据库 API（Wind、Bloomberg、Refinitiv、tushare、AkShare、iFinD 等）、交易所官方行情接口、
  经济指数数据（CPI/GDP 等官方统计）、官方统计/央行发布、内置数据抓取工具（如 stock_financials、westock-data 等）
- 第二级 = 证券公司/投行研究报告、权威金融机构分析文章、基金评级机构报告、专业财经媒体深度分析
- 第三级 = 非金融类媒体新闻、自媒体/公众号文章、博客/论坛帖子、百科条目、搜索引擎摘要/聚合站转载、
  社交平台信息、来路不明的网页抓取

**第一层（GT 基线，由 grounding 检查点度量，评分官不在此重复扣分）：**
- Q1-Q4 每题三元检查点（base_price / latest_price / answer，4:4:2 加权）
- 跨 4 题等权平均 → grounding_pass_fraction_weighted
- D1 第一层基线 = grounding_pass_fraction_weighted（引用核验率不再计入）
- 每个未通过的 grounding 检查点按其组内权重降低第一层基线（CF5 仍对该检查点记 0 分）
- 说明：价格/最新价/答案数值是否正确由上述检查点度量，评分官**不得**在 D1 就"数值算错"再扣分。

**第二层扣分锚点（不可数值核验的来源质量，对号入座逐条登记；扣分点合成为系数后与第一层基线取平均）：**
- 关键承重量化数据取自第三级来源而第一/二级可用 → major（−1）
- 关键承重量化数据无任何来源（凭记忆给数）→ severe（−2）（与 CF1 链呼应）
- 非关键数据点取自第三级来源 → minor（−0.5）
- 引用来源缺日期/as-of 时点 → minor（−0.5）
- 声明悬空（声称"据 Wind"等但无具体可核验引用条目）→ major（−1）
- 声明悬空（内置数据抓取工具例外）：声明使用内置工具且标注工具名称 → 不扣分（0）
- 关键数据取自第二级来源（可接受但非最优），且未回溯到第一级原始来源 → minor（−0.5）
- 用明显陈旧数据冒充最新数据 → 与 CF4 链呼应（D1 封顶为等级 1；数值不符本身由 CF4 度量）

## D2 方法正确性与可操作性（权重20，含原 D5 可操作性锚点）

**第一层（GT 基线，由 methodology 检查点度量，评分官不在此重复扣分）：**
- 复权口径正确性（Q1-Q4 各 `*_adjustment` 检查点）
- 基准日选择正确性（Q1-Q4 各 `*_base_date` 检查点）
- 答案数值正确性（`*_answer` 检查点，同时标 methodology:true）——含收益率公式是否正确、是否按要求四舍五入
- D2 第一层基线 = 上述 methodology 检查点的通过率
- 说明：复权口径选错、基准日取错、Q1 基准价取错、收益率公式错误、未四舍五入等**数值/口径对错**
  均由上述检查点度量，属于第一层；评分官**不得**在 D2 就这些再扣分（两层不重叠）。

**第二层扣分锚点（不可数值核验，评分官登记；原 D5 可操作性锚点转入）：**
- 未标注各数据点的 as-of 时点（口径标注缺失，非数值对错）→ minor（−0.5）
- 数据来源不可复现（仅给数字不给 API/URL）→ minor（−0.5）

## D3 完整性（权重15）

- 4 题中每缺失一题的完整回答（数值 + 来源 + 口径）→ minor（−0.5 /题）
- 缺少数据来源声明 → minor（−0.5 /题）
- 缺少复权类型声明 → minor（−0.5 /题）

## D4 分析质量与洞察（权重0，取消评分）

> D4 权重=0，本维度不参与评分。原 D4 的分析洞察锚点（如说明基准日选择理由、复权方式区别等）
> 不再作为独立扣分维度。作品的分析质量仍可在 D2（方法正确性）中通过方法选择的合理性间接体现。

## D5 可操作性与适配性（权重0，取消评分）

> D5 权重=0，本维度不参与评分。原 D5 的可操作性锚点（as-of 时点标注、数据来源可复现性）
> 已转移至 D2，由 D2 统一评分。

## D6 外部工具链完整度（权重25，本家族关键计算步骤界定）

- 关键计算步骤 = 市场数据 API 调用（获取复权价/指数点位）+ 收益率计算
- 数据获取未经 API/工具执行（无调用轨迹，凭记忆给数）→ severe（−2）（与 CF1 链呼应）
- 部分题目用了工具获取、其余题目凭记忆 → major（−1）
- 工具调用失败后未换源/未处理，直接用降级数据 → minor（−0.5）
- 完全无工具使用证据（全部凭手算/口算/记忆）→ severe（−2）
- D6 权重 25：本任务核心是数据获取的稳定性，工具链覆盖度是评分重点
