# S17 盲评扣分锚点（马来西亚对八大贸易伙伴贸易差额查询）

> **每维度 4 分起评，逐条登记 `{issue, severity, points, evidence}`；轻微 −0.5 / 明显 −1 / 严重 −2。**
> 本文件只给「情形 → 既有严重度」映射：不含任何期望数值，不改权重，不新增严重度档，不设加分项。
>
> 权重：D1:45 D2:15 D3:15 D4:0 D5:0 D6:25
>
> **两层不重叠（disjointness）**：D1 与 D2 是客观维度，其「数值/公式是否正确」由**第一层
> 检查点**负责度量。评分官在这两个维度上的扣分**仅限不可数值核验的缺陷**——来源含金量、
> 口径是否声明、判定是否有可操作方法论支撑。**不得**因检查点已经度量的数值对错在此再扣一次分。
>
> **本题的特殊性，评分官务必先读**：本题的核心问题（"贸易差额最大的是哪一个"）依赖候选
> 作品自己声明的"最大"定义（顺差最大 / 绝对值最大）——**本文件不透露、也不暗示哪个国家
> 是"正确答案"**。评分官只核验候选作品是否明确声明了定义、是否按自己声明的定义给出了
> 内部自洽的结论，不与评分官自己心中的答案做比对。

---

## D1 数据完整性与依据（权重 45）

**第一层（GT 基线，评分官不在此重复扣分）：**

- 8 个贸易伙伴×3 项（出口/进口/差额）+ 全国合计×3 项，共 27 个 grounding 检查点
- D1 第一层基线 = 上述检查点的通过率
- 说明：具体数字取得对不对，已由第一层度量，评分官不得在此重复扣分。

**第二层扣分锚点（不可数值核验的来源质量，评分官登记）：**

| 情形 | 扣分 |
|---|---|
| 关键贸易数据无来源，凭记忆编出来的 | 严重 −2 |
| 关键数据用了非官方渠道（自媒体/社区帖转述），而马来西亚统计局(DOSM)官方公报本身可查 | 明显 −1 |
| 引用了数据但未注明统计口径（出口FOB/进口CIF）或统计区间（1-2月累计 vs 单月） | 明显 −1 |
| 引用了数据但未注明数据来源与发布时点 | 轻微 −0.5 |
| 凭空编造分国别数字，且无法追溯来源；诚实说明未取到数据不算失真 | 严重 −2（与 CF1 链呼应） |

## D2 方法正确性（权重 15）

**第一层（GT 基线，评分官不在此重复扣分）：**

- `balance_*_consistency`（consistency，9项）：候选作品自己报的出口-进口是否等于自己报的差额
- `balance_definition_declared`（present）：是否声明"最大"的定义
- D2 第一层基线 = 上述 methodology 检查点的通过率
- 说明：**差额算术闭环已由 `balance_*_consistency` 检查点机械核验**，评分官不得在此就
  "差额算错了"再扣一次分。

**第二层扣分锚点（不可数值核验的口径/概念缺陷，评分官登记）：**

| 情形 | 扣分 |
|---|---|
| 声明了"最大"的定义，但结论与该定义在逻辑上不一致（如声明用"绝对值最大"，结论却只比较了顺差方向的国家、未把逆差国家的绝对值纳入比较） | 严重 −2 |
| 全文从未声明"最大"采用的是哪种定义，直接给出一个国家名称作结论 | 明显 −1（与 D1 第二层的口径缺陷不重复计分——此处针对方法论上"未声明就下结论"这一问题本身） |
| 把"1-2月累计"与"单2月"两种统计区间的数字混用 | 明显 −1 |
| 把"出口FOB"与其他口径（如到岸价）混用而未注明 | 轻微 −0.5 |

## D3 完整性（权重 15）

| 情形 | 扣分 |
|---|---|
| 8 个贸易伙伴中有遗漏，未逐一给出出口/进口/差额三项数据 | 明显 −1（每缺一国累加，封顶严重 −2） |
| 只给出结论国家，未展示逐一对比的数据表格/列表 | 明显 −1 |
| 未按声明的定义给出一个明确的结论国家（如列完数据后不下结论，或说"都有可能"） | 明显 −1 |
| 呈现顺序混乱、未按差额排序，导致难以核对（结构性问题，非数值错误） | 轻微 −0.5 |

## D6 外部工具链完整度（权重 25）

**本家族的关键计算步骤**：贸易数据检索（需数据源/工具查询，而非凭记忆给数）+ 差额算术复核。

| 情形 | 扣分 |
|---|---|
| 完全无任何工具/检索证据（纯记忆给出全部8国数据） | 严重 −2 |
| 声称检索了数据，但无检索轨迹、无可复现来源 | 明显 −1 |
| 部分国家有检索证据，部分国家没有 | 轻微~明显 −0.5~−1 |
| 工具调用失败后未处理、未换源，直接使用降级或缺失的结果 | 轻微 −0.5 |

D6 只评工具使用行为，不评数据来源层级（那由 D1 负责）。
