# S14 盲评扣分锚点(中证转债指数2022-2024回撤复盘)

> **两层不重叠(disjointness)硬约束**: D1 与 D2 是客观维度, 其"数值/公式是否正确"由
> **第一层检查点**负责度量。评分官在这两个维度上的扣分**仅限不可数值核验的缺陷**——
> 来源含金量、口径是否声明、概念是否误解、判定是否有可操作方法论支撑。
>
> 评分官**不得**因"某个峰谷点位/日期取错了""跌幅%算错了""溢价率收缩pp对不上""峰谷价格
> 与跌幅%互算不一致"在 D1/D2 再扣分: 那些已由第一层检查点(40个外部真值键 + reconcile/
> consistency 闭合)度量。各维度下方已按"第一层(评分官不在此扣分)"与"第二层扣分锚点
> (评分官登记)"分列。
>
> **本容器的一处特殊说明**: 均值/算术平均口径的溢价率**没有**独立的第一层数值真值
> (gold facts 对该口径只给出部分轮次的单点数值, 数据不完整, 不足以支撑四轮一致的
> 真值序列——见 gt_recipe.yaml design_note)。因此:
> - 若候选作品明确声明使用均值/算术平均口径并给出该口径下的数值, 这些数值**不会**
>   被拟合百元口径的真值键判错(不适用该口径的 grounding 检查点转NA, 不计入分母)——
>   但也**得不到**该口径独有的第一层数值核验。
> - 若候选作品声明用了某口径, 但报告的数值实际匹配另一口径的真值序列(自相矛盾),
>   这属于**第二层**锚点"口径声明与数值不符"的辖区, 不是第一层的判定对象。

## D1 数据完整性与依据(权重30, 本家族第一级来源界定)

**第一层(GT 基线, 评分官不在此重复扣分):**

- 逐轮峰谷日期(月份级, YYYYMM)与价格的 grounding 检查点(R1/R3/R4 各4个, R2因W型
  双腿有8个)
- 逐轮收盘口径最大跌幅%的 grounding 检查点(4个)
- 逐轮沪深300(或对应窗口)基准对照收益率%的 grounding 检查点(R1/R3/R4各1个, R2因
  两腿各1个共2个)
- 逐轮拟合百元口径溢价率水平的 grounding 检查点(R1/R2各2个前后值, R3/R4分别1/2个,
  R3起点因数据缺口不设)
- 逐轮修复交易日数的 grounding 检查点(R1估值×2变体路由为1个有效判定, R2估值, R3
  估值+点位, R4点位, 共5个有效判定)
- R4 信用事件标志性事实(set_match, 1个)
- 以上全部 grounding 检查点**等权**构成 grounding 通过率; D1 第一层基线 = grounding
  检查点通过率(引用核验已关闭, citation_policy: none)
- 候选作品若只实质复盘题面下限的2轮, 未覆盖轮次的检查点全部转 NA 并从分母剔除,
  grounding 基线自动退回到"只由已覆盖轮次的检查点构成", 不因少覆盖而被拉低基线

**第二层扣分锚点(不可数值核验的来源质量与口径声明, 对号入座逐条登记):**

| 情形 | 扣分 |
|---|---|
| 关键点位/日期/溢价率数值完全无来源声明(凭记忆给出关键数字) | −2 |
| 关键承重数据取自第三级来源(自媒体/博客/公众号复盘文章), 而第一级(中证指数公司/交易所)或第二级(主流券商研报)来源显然可用 | −1 |
| 声明悬空: 声称"据中证指数公司/据Wind"但无具体可核验的引用条目 | −1 |
| 声明使用某溢价率口径(拟合百元/均值/算术平均), 但报告的数值实际匹配另一口径的真值序列 | −1 |
| 全文未声明所用的溢价率口径 | −1 |
| 引用信用事件(岭南/广汇/搜特)的日期或金额无来源支撑 | −0.5 |
| 引用点位未标注收盘/盘中口径(gold facts 默认收盘口径, 盘中极值需单独标注) | −0.5 |
| 关键数据取自第二级来源(媒体转引研报数字), 未回溯到一级原始来源 | −0.5 |

**不得在此扣分的情形**: 峰谷点位/日期/跌幅%/溢价率水平/修复天数本身的数值对错——
那些已由第一层的 40 个外部真值键度量; 峰谷价格与自报跌幅%是否互算一致——那由 D2
第一层的 consistency 检查点度量, 在此再扣即为双罚。

**本家族第一级来源界定:**

- 中证转债指数(000832)点位与区间涨跌幅: 中证指数有限公司官网/factsheet, 交易所行情,
  Wind/同花顺终端
- 转股溢价率(任一口径): 主流券商固收团队测算研报(华创/兴业/华安/东吴等, 需标注口径
  与测算方法) = 第二级; 若研报直接转引指数公司或交易所披露的原始成分券数据并可溯源
  = 第一级
- 信用事件(岭南/广汇/搜特)日期与金额: 交易所/发行人公告, 中国债券信息网, Wind
- 沪深300/国证A指同期涨跌幅: 中证指数有限公司, 交易所行情

## D2 方法正确性(权重20)

**第一层(GT 基线, 评分官不在此重复扣分):**

- 逐轮"峰谷价格 → 自报跌幅%"的互算一致性检查点(4个 consistency, 直接核验 gold
  facts 自身列为最高发陷阱的"cross-foot 矛盾")
- 逐轮"溢价率收缩pp → 自报前后溢价率之差"的闭合检查点(R1/R2/R4各1个 reconcile,
  R3因起点数据缺口不设)
- caliber_declared_global(count_min形态的present, 至少一处声明口径)
- D2 第一层基线 = 上述 methodology 检查点的通过率

以上全部属第一层。**跌幅%与自引峰谷点位算不出来、溢价率收缩pp与自引前后水平算不
出来、全文未声明任何口径——均由第一层度量, 评分官不得在 D2 就这些再扣分。**

**第二层扣分锚点(不可数值核验的方法论缺陷, 评分官登记):**

| 情形 | 扣分 |
|---|---|
| 将正股下跌导致的溢价率被动走阔误判/误述为"主动压缩"(概念混淆——正股跌→平价降→溢价率机械被动走阔, 而非被动压缩; 被动压缩只发生在正股快涨期) | −1 |
| 溢价率口径静默切换、未标注(前文用拟合百元口径叙事, 后文引用均值/算术平均口径数值而不加区分, 造成"同一轮估值既压缩又走阔"的表观自相矛盾) | −2 |
| pct(百分点)与%(相对变化)混用导致同一收缩幅度出现两个互斥读数(如把"-10.9pp"误写/误算成"-41%"而不加说明) | −1 |
| 主动/被动判定停留在事后贴标签, 全文未使用任何"转债与正股同期涨跌幅之差"一类可操作的判定方法, 纯靠语感定性 | −1 |
| 把2024年6-8月信用冲击轮归因为"债市走熊/利率上行"(方向性错误——该轮恰发生于债牛/资产荒环境, 归因错误意味着方法论上把资产端风险与负债端赎回混为一谈) | −1 |
| 收盘/盘中口径混用而未标注(如跌幅数值忽而引用收盘、忽而引用盘中极值, 不加区分地并列) | −0.5 |

## D3 完整性(权重15)

| 情形 | 扣分 |
|---|---|
| 只复盘1轮而非≥2轮, 或把2022-2024整体当一轮处理 | −2 |
| 覆盖轮次数达标, 但"起止时间/最大跌幅%/溢价率收缩pct/收缩逻辑判定/修复交易日数"五要素中某一要素在**所有**已复盘轮次中全文缺席 | −1 每缺席一项要素(封顶累计至该维度归零)|
| 两个跨轮问题(修复速度依赖权益走势; 主动扩张vs被动压缩条件)中任一未正面回答, 仅罗列单轮描述拼凑 | −1 各计 |

| 全文未声明所用的指数口径(收盘/盘中)——溢价率口径声明缺失已在D1/D2度量, 此处专指指数点位口径 | −0.5 |

## D4 分析质量与洞察(权重30, 本容器主维度)

| 情形 | 扣分 |
|---|---|
| 把2022年8-12月W型回撤当单轮处理, 未识别两腿性质差异(leg1正股驱动/被动跟随 vs leg2理财赎回驱动的负债端主动杀估值、且与正股走势脱钩) | −1 |
| 主动/被动判定未辨析三类杀估值触发器(负债端-固收+赎回 2022年2月 / 负债端-理财负反馈 2022年11-12月 / 资产端-信用风险 2024年6-8月)的传导路径与受伤券种结构差异, 三轮判定读起来像同一套模板换了日期 | −1 |
| 未提及2024年实质违约(搜特2024-05-17首例实质违约/岭南2024-08-14到期违约)对转债定价范式的结构性影响(债底从"刚性下限"变为"信用分层的软约束"), 把第四轮修复慢仅归因于周期位置而非结构性范式迁移 | −0.5 |
| 未识别或混淆"点位修复速度"与"估值修复速度"可以背离甚至反向(第四轮: 点位31个交易日收复前高, 但估值因正股暴涨被动压制、4个月以上未完全修复)——把两者混为一谈叙述为"已经修复" | −1 |
| 修复速度对权益的依赖关系停留在"权益涨则转债估值修复"的单向浅层描述, 未区分"权益反转推动估值修复"(第三轮, 权益V型反转+估值已压至极低, 64个交易日快修复)与"权益涨太快反而推迟估值修复"(第四轮, 正股暴涨被动压制估值)两种相反机制 | −1 |
| 主动扩张的条件判断未触及"资产荒/纯债收益率下行+增量负债(固收+/理财扩容)+供给收缩+权益预期改善未兑现"四者共振这一结构性条件, 仅泛泛断言"市场情绪好则溢价率扩张" | −1 |
| 存在明显的叙述与数值自相矛盾(如数值显示某轮转债跌幅大于正股, 文字却称"债底缓冲、跌幅远小于正股"), 且非笔误 | −2 |

**加分不存在**: 本框架为纯扣分制。作品若额外讨论了2025年后续验证、机构行为视角
(固收+/理财/年金负债端结构)等, 不扣分即为其回报, 不设加分项。

## D6 外部工具链完整度(权重5, 本家族关键计算步骤界定)

**本家族的关键计算步骤(两步):**

1. 历史点位/溢价率/基准对照数据检索(需财务数据工具/数据库检索, 而非凭记忆给出关键数字)
2. 跌幅%/溢价率收缩pp的算术复核(能展示或至少清楚交代"如何从峰谷点位算出跌幅%"的过程)

| 情形 | 扣分 |
|---|---|
| 关键点位/溢价率数据完全无任何工具调用证据(纯记忆给出所有关键数字) | −2 |
| 部分轮次有检索证据、部分轮次无 | −1 |
| 跌幅%/溢价率收缩pct的算术复核过程完全未展示(既不给公式也不给中间数字) | −0.5 |
| 工具调用失败后未处理、未换源, 直接使用降级或缺失的结果而未说明 | −0.5 |

**D6 只评工具使用行为**——计算执行轨迹与工具链覆盖度, 不评数据来源层级(那由 D1
负责)。只认作品正文与 tool_evidence 中可见的证据, 不脑补。

**判定尺度说明**: 若作品在正文中完整展示了峰谷点位到跌幅%的推导算式(即使没有独立
代码文件), 视为该步骤有计算轨迹——D6 不强制要求 `.py` 文件, 但要求计算过程可查。

**本容器已启用 CF3**(描述了分析但未产出可核验数值, 封顶 D2+D3 到等级1)。因此"零数据
复盘"(只泛泛描述几轮下跌而不给任何数值)由 CF3 兜底封顶, 本维度的扣分聚焦于"给了
数值但工具证据不足"这一更细粒度的失败模式, 两者不重叠。
