# S12 盲评扣分锚点（put-write-backtest）

> **两层不重叠（disjointness）硬约束**：D1 与 D2 是客观维度，其「数值/公式是否正确」由
> **第一层检查点**负责度量。评分官在这两个维度上的扣分**仅限不可数值核验的缺陷**——
> 来源含金量、口径是否声明、概念是否误解、数值是否符合组合结构的常识。
>
> 评分官**不得**因「某个逐年回报取错了」「累计与年化对不上」「夏普算错了」在 D1/D2 再扣分：
> 那些已由第一层检查点度量。各维度下方已按「第一层（评分官不在此扣分）」与
> 「第二层扣分锚点（评分官登记）」分列。
>
> **本容器的一处特殊说明**：D1 第二层有一条关于 ETF 腿口径选择的锚点。它不违反不重叠规则，
> 因为第一层与第二层问的是**两个不同的问题**：
> 第一层问「你报的沪深300 数字，与你所选口径的真值是否一致」——沪深300 逐年检查点按作品
> 自己声明的口径路由到对应真值序列，用全收益的只对全收益负责，用价格指数的只对价格指数负责，
> 两种合法口径**都能在第一层拿满分**；
> 第二层问「选这个口径在经济上是否恰当」——这是一个口径**选择**的判断，第一层完全没有度量。
> 所以评分官既不得因「某个逐年数字算错了」在 D1 扣分（第一层已度量），
> 也不得以「反正第一层放过了它」为由放弃口径选择这条锚点。
>
> 另请注意：中间量披露（无风险利率、两组袖子收益、再平衡口径声明、波动率频率声明）
> 已由第一层的一个汇总检查点度量。评分官**不要**在 D2 就这些披露缺口再扣分——
> 相关完整性问题请在 D3 处理，且 D3 的锚点已避开这四项。

---

## D1 数据完整性与依据（权重 25，本家族第一级来源界定）

**第一层（GT 基线，评分官不在此重复扣分）：**

- 中债-综合财富（总值）逐年回报的 6 个检查点（数值准确性，含口径误用的捕获——
  误用净价或全价会使这 6 个检查点整体失败）
- 沪深300 逐年回报的 6 个检查点（`csi300_2020..2025`）。按作品声明的 ETF 腿口径
  路由到全收益或价格指数真值序列比对；两种合法口径都能通过。作品若从未交代口径，
  评分器按数值全组一次性推断；若连数字都没报，这 6 个检查点转 NA（不扣分、不计入分母）
- 上述 12 个 grounding 检查点**等权**构成 grounding 通过率
- D1 第一层基线 = grounding 检查点通过率（引用核验已关闭，citation_policy: none）

**第二层扣分锚点（不可数值核验的来源质量与口径声明，对号入座逐条登记）：**

| 情形 | 扣分 |
|---|---|
| 关键市场数据（债券指数回报、沪深300 回报、期权合约事实）完全无来源声明 | −2 |
| 关键承重数据取自第三级来源（自媒体/博客/百科/搜索摘要），而第一级或第二级来源显然可用 | −1 |
| 声明悬空：声称「据 Wind / 据中债估值中心」但无具体可核验的引用条目 | −1 |
| 声称直接回测了 510330（华夏沪深300ETF）的期权，或把代理标的的数据标注为 510330 而不说明代理关系 | −1 |
| 引用来源缺日期或 as-of 时点 | −0.5 |
| 关键数据取自第二级来源（媒体转引、数据平台二次加工），未回溯到一级原始来源 | −0.5 |
| 未声明债底仓所用的指数口径——即未区分财富（总值）、全价、净价三者 | −0.5 |
| 明确声明 ETF 腿采用沪深300 **价格指数**（000300.SH）口径，而非**全收益**（H00300.CSI）口径 | −0.5 |

**关于最后一条的判定依据**：以作品自己的口径声明为准，而非靠数值反推。ETF 持有人实际获得
分红，全收益口径更贴近对照组的真实持有体验；价格指数口径系统性忽略了这部分收益，
是可接受但非最优的选择。若作品未声明用了哪种口径，适用上一条（未声明口径）而非本条。

价格指数口径的逐年数字在第一层**能够通过**（它有自己的真值序列）。本锚点仍扣 0.5，
扣的不是「数字错了」而是「口径选择欠佳」——两件事，不构成双罚。反过来说，
一份用价格指数但逐年数字准确的作品，只应在此损失 0.5，不应在第一层被判错。

**不得在此扣分的情形**：
- 作品误用净价或全价口径导致债底仓逐年数值错误——那是第一层 6 个中债检查点度量的对象
- 作品所报的沪深300 逐年数字与其**所声明口径**的真值不符——那是第一层 6 个
  `csi300_*` 检查点度量的对象。「声明用全收益但数字是价格指数」这类自相矛盾同样已由
  第一层捕获（声明决定比对哪条序列，数字随即失配），在此再扣即为双罚

**本家族第一级来源界定：**

- 中债-综合财富（总值）指数：中债估值中心官网、中国债券信息网、Wind 终端中债指数模块
- 沪深300 指数（价格与全收益）：中证指数有限公司 factsheet、Wind 终端
- 期权合约规格、挂牌事实与保证金规则：上交所/深交所正式公告与合约基本条款
- 无风险利率：中债国债收益率曲线、CFETS

## D2 方法正确性（权重 35，本容器主维度）

**第一层（GT 基线，评分官不在此重复扣分）：**

- 策略组累计与年化的**双向互推闭合**（两个 reconcile 检查点）
- 对照组年化的外部锚定（宽容差，容纳两种 ETF 腿口径）
- 对照组累计由年化单向推导的闭合
- 两组夏普比率与各自自报的年化收益、无风险利率、波动率的闭合
- 跨组差异闭合：两组年化之差与 5% 袖子收益之差的对应关系
- 中间量披露汇总检查点（5 项中至少 3 项）
- D2 第一层基线 = 上述 methodology 检查点的通过率

以上全部属第一层。**年化方式选错（如用算术平均而非几何）、累计与年化互不闭合、
夏普公式用错、跨组差异与袖子收益不匹配、中间量披露不足——均由第一层度量，
评分官不得在 D2 就这些再扣分。**

**第二层扣分锚点（不可数值核验的方法论缺陷，评分官登记）：**

| 情形 | 扣分 |
|---|---|
| 完全无任何工具使用证据的同时，方法叙述也无可复核的计算路径（纯断言式结论） | −2 |
| 把「5% 本金作保证金」当成「5% 名义敞口」或「5% 股票仓位」，未澄清杠杆效应，导致策略尾部风险被系统性低估 | −1 |
| 把卖沽权利金论述为无风险增强、稳赚收益，或声称该策略单边优于对照组而不识别 short put 的下行承接义务 | −1 |
| 最大回撤数值与组合结构明显不符——例如一个 95% 低波债券 + 5% 股票敞口、且穿越了多次指数急跌的组合，却报出低于 1% 或高于 10% 的最大回撤——且未给出任何计算依据 | −1 |
| 年化波动率数值与组合结构明显不符——例如报出两位数的组合年化波动率（95% 仓位是年化波动约一个多百分点的债券指数） | −1 |
| 换仓与被指派逻辑缺失或明显错误——例如假设所有卖出的看跌期权都到期归零、从不被行权，因而不承担任何下行损失 | −1 |
| 回撤计算口径与持有标的不匹配——例如策略实际持有含票息再投资的财富指数，却用价格序列计算回撤 | −0.5 |

**关于回撤与波动率两条锚点的说明**：这两个量在本容器中**没有任何第一层检查点覆盖**——
最大回撤不出现在任何闭合关系里，年化波动率虽出现在夏普闭合的分母，但只要作品把夏普也
按同一个错误的波动率算出来就依然自洽。因此它们的合理性完全依赖评分官判断，
属第二层的合法辖区，不构成双罚。

## D4 分析质量与洞察（权重 10）

| 情形 | 扣分 |
|---|---|
| 收益增强分析停留在「卖沽收权利金所以增强」的浅层描述，未涉及时间价值衰减或隐含波动率风险溢价，也未说明增强适用的市场环境 | −1 |
| 回撤分析只说「卖沽有尾部风险」，未对比两种做法回撤的**形态差异**（集中爆发于急跌窗口的尖峰形 vs 随指数渐进的满 beta 形） | −1 |
| 未区分「袖子层面差异」与「组合层面差异」——把 5% 袖子的超额放大叙述为组合层面的大幅跑赢，而实际上 95% 债券底仓主导了绝对水平、两组差异被稀释为二阶项 | −1 |
| 完全未提及策略在单边上涨市的机会成本（卖沽收益封顶于权利金，落后于满额捕捉上行的对照组） | −1 |
| 存在明显的叙述与数值自相矛盾——例如数值显示策略组跑输，文字却声称全面优于对照组，且非笔误 | −2 |

**加分不存在**：本框架为纯扣分制。作品若对期权数据可得性、假设敏感性等做了额外讨论，
不扣分即为其回报，不设加分项。

## D6 外部工具链完整度（权重 15，本家族关键计算步骤界定）

**本家族的关键计算步骤（四步）：**

1. 逐年市场数据获取（两个指数的逐年回报——从数据源拉取或明确引用，而非凭记忆给数）
2. 组合收益聚合（逐年按 95/5 加权，再逐年连乘得累计，开方得年化）
3. 卖沽袖子的权利金与损益模拟
4. 风险指标计算（年化波动率、最大回撤、夏普比率）

| 情形 | 扣分 |
|---|---|
| 完全无任何工具使用证据——四个关键步骤全部凭手算或记忆 | −2 |
| 宣称的计算未经代码/工具执行：无执行轨迹，亦无可复现的产物 | −1 |
| 工具链覆盖不完整：部分关键步骤有工具支撑，其余关键步骤没有 | −0.5 ~ −1 |
| 工具调用失败后未处理、未换源，直接使用降级或缺失的结果 | −0.5 |
| 工具输出与正文数值不一致（如代码输出与表格中的数字对不上），且未解释差异 | −0.5 |

**D6 只评工具使用行为**——计算执行轨迹与工具链覆盖度，不评数据来源层级（那由 D1 负责）。
只认作品正文与 tool_evidence 中可见的证据，不脑补。

**判定尺度说明**：若作品在正文中完整展示了推导公式与分步计算过程（即使没有独立代码文件），
视为该步骤有计算轨迹——D6 不强制要求 `.py` 文件，但要求计算过程可查、可复现。

**本容器的一处特别说明**：本任务未启用 CF3（描述了分析但未产出计算结果的封顶规则）。
因此「没有真的算」这一失败模式的惩罚，完全由本维度的扣分承担（最重 −2 使本维度归零，
损失全部 15 权重），并叠加捏造的数字通不过第一层闭合检查所造成的 D2 损失。
请按上表如实登记，不要因为「反正 CF 会兜住」而放宽尺度。
